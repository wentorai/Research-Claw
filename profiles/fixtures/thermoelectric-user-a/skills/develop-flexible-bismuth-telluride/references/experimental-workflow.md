# Experimental Workflow for Flexible Bi2Te3

## Contents

1. Define use case and controls
2. Establish process window
3. Build a designed series
4. Characterize coupled properties
5. Integrate and validate devices

## 1. Define use case and controls

Specify generator/cooler/sensor function, temperature window, heat-flow direction, radius/strain, cycle count, environment, footprint, output target, skin/surface constraint, and fabrication budget. Select a p/n pair and architecture before choosing deposition.

Use a rigid substrate with the same film/process as a material control and a bare/seeded flexible substrate as a process/mechanics control. Add electrode/interface controls when contact changes are likely.

## 2. Establish process window

Measure substrate glass transition or service/anneal ceiling, shrinkage, outgassing, roughness, surface energy, barrier performance, and thermal expansion. For sputtering/evaporation/electrodeposition/printing, record pressure, power/current, target/ink, rate, substrate temperature, thickness map, atmosphere, and post-treatment. Track recovered/final Bi/Te/Sb composition and oxidation.

## 3. Build a designed series

Vary composition, thickness, texture, porosity, binder/conductive phase, surface treatment, anneal, and neutral-plane geometry deliberately. Use factorial designs for coupled anneal–substrate or binder–porosity effects. Include replicate deposition/print batches and spatial mapping across area.

Preserve specimens for cross-section, composition, phase, texture, adhesion, and crack-density post-mortem. Avoid using only the least damaged coupon for transport.

## 4. Characterize coupled properties

- composition: XRF/EDS calibrated by WDS/ICP where needed; map Te loss and segregation;
- phase/texture: XRD plus pole figures/GIXRD/EBSD when direction matters;
- morphology/mechanics: thickness, roughness, porosity, residual stress, adhesion, crack density, curvature/strain;
- electrical: four-probe/sheet resistance with geometry and contact correction; Hall only after linear field checks;
- Seebeck: calibrated gradient, contact correction, direction, uncertainty;
- thermal: direction-appropriate method and substrate/film inverse-model sensitivity;
- cycling: record in-cycle resistance/output, not just after flattening.

Pair thermoelectric and bending data on the same state. If bending itself changes texture, contacts, or temperature gradient, measure those intermediates.

## 5. Integrate and validate devices

Screen electrodes and barriers for initial contact resistance, adhesion, reaction, and cyclic strain. Build small p/n coupons before arrays. Model geometry, fill factor, substrate heat spreading, contact thermal resistance, and source/sink.

Measure thermocouples at active junctions, complete I–V/P–I curves, `Voc`, `Rint`, `Pmax`, temporal stability, curvature, and ambient/source/sink conditions. Repeat independent devices. Combine bending with thermal/humidity/current stress in an order reflecting use, then cross-section failures.

Advance only when material, interface, device, and reliability thresholds are simultaneously met.
