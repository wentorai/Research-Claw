# v0.8.2 发布验收

## 发现

v0.8.1 的公开 `install.sh` 能从 Gitee 获取主仓,但随后仍按 `.gitmodules`
从 GitHub 获取 `ppt-master`。在真实隔离安装中,GitHub 连续两次返回
`Error in the HTTP2 framing layer`,安装在第 5/8 步终止。

## 修复

- Gitee 主仓路径优先使用 PPT Master 上游文档提供的 AtomGit 镜像。
- 显式 GitHub 主仓路径优先使用 GitHub。
- 两条路径互为回退,并使用 `http.version=HTTP/1.1` 避免已复现的 HTTP/2 故障。
- Git submodule 仍按 Research-Claw 记录的 gitlink 检出固定提交。

## 运行时证据

- AtomGit 精确抓取:
  `8ac18bb381a7c62802316354266f558b3ccae1f7`。
- macOS arm64、隔离 HOME、Gitee 主仓的完整 8 步安装通过,耗时 2 分 26 秒。
- 安装结果:
  Research-Claw `9a2daed371ca11400033abc137394f5cf6f26ebb`,
  PPT Master `8ac18bb381a7c62802316354266f558b3ccae1f7`,
  Research-Plugins `1.4.8`。
- `ensure-config.cjs` 连续复跑后配置 SHA-256 不变。

正式发布提交以 `v0.8.2` 注解标签及容器
`org.opencontainers.image.revision` 标签为权威身份。
