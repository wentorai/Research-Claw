# v0.8.1 发布验收

本记录只写本轮亲自复现的结果。历史报告和较早构建的绿灯不作为最终证据。

## 代码与配置

- `pnpm build`:通过。
- 根仓 `npx vitest run`:93 个测试文件通过、4 个跳过;1460 个测试通过、10 个跳过、22 个待实现标记。
- Dashboard `pnpm --filter dashboard test`:145 个测试文件、2243 个测试全部通过。
- Supervisor 与 Research-Claw Core 的 TypeScript 无输出编译:通过。
- Bash 语法检查:原生安装、Docker 安装、更新、启动和容器入口脚本通过。
- Windows PowerShell 语法检查:用 ARM64 PowerShell 7.4 容器解析 `install-docker.ps1` 与 `update-research-claw.ps1`,通过。
- `scripts/secret-scan.sh --all`:未发现 Git 跟踪文件中的明文密钥。
- `git diff --check`:通过。

第一次在受限执行环境运行根仓测试时,7 个 RTSP HTTP 用例因禁止监听 `127.0.0.1` 而超时。该轮判为环境无效;在允许本地回环监听的环境重跑后,同一测试文件 20 个用例通过、2 个真实外部源用例按条件跳过,根仓全量结果如上。

## 真实隔离网关

`pnpm verify:e2e` 使用临时配置、临时状态目录和隔离端口运行,结果:

- 旧 Dashboard 构建版本 `0.8.1-stale` 被网关拒绝,当前 `0.8.1` 正常连接。
- RPC 业务错误、带错误码异常和未知异常均按约定分级,敏感内容未进入公开错误。
- Research-Plugins 冷启动自检识别 82 个挂载工具;缺失工具、截断技能和探针失败均可观察且不阻止健康启动。
- 定时任务主模型失败时只在符合条件时转入备用模型;用户主动中止不会触发备用调用。

## 幂等与破坏性验证

- 将本机真实安装配置复制到临时目录,连续运行两次 `ensure-config.cjs`;第二次前后 SHA-256 相同,证明字节级幂等。原配置未被修改,配置内容未输出。
- 单实例入口:测试先在旧安装器的重复启动逻辑上失败;改为 `install.sh → run.sh` 唯一入口后通过。临时去掉 `exec` 再次使测试失败,还原后通过。
- 其余本轮变异覆盖:语义记忆默认值、占位渠道清理、定时任务启用判断、重复任务替换、Supervisor 空响应健康状态、Docker 回滚容器名、旧 Dashboard 版本比较。每次破坏均使对应测试失败,还原后重新转绿。

## 已知测试输出

- Dashboard 测试会输出 React `act(...)` 和 KaTeX quirks-mode 警告,但没有测试失败。这些是测试运行器噪声,未出现在生产构建或真实网关验收中。
- Vite 报告已有模块同时被静态和动态导入,以及大 chunk 提示;构建成功,不影响本次安装与升级修复的正确性。

## Docker

- 在 ARM64 主机从 ARM64 `node:22-slim` 冷构建候选镜像,完整依赖安装、Research-Claw 构建和镜像导出通过,没有平台错配警告。
- 镜像检查:架构为 `linux/arm64`;Research-Claw `0.8.1`、OpenClaw `2026.6.1` 与 OCI revision 可从容器内读取。
- `ffmpeg` 与 `ffprobe` 均可执行,版本为 Debian 5.1.9。
- `RC_TEST_DOCKER_IMAGE=research-claw:0.8.1-rc pnpm verify:docker`:通过。临时容器健康启动,配置、数据库、工作区和 OpenClaw 状态分别持久化;重启仍健康;故意写入损坏配置后,错误在容器日志中可观察且入口监督进程仍存活。
- 发布构建仍须用最终 Git SHA 写入 OCI revision,并从同一提交生成 Linux/amd64 与 Linux/arm64 清单。
